# 主题变更：《旅行青蛙》→《御风启程》（动态飞翔滑行旅行）

> 阶段评审文档。用户决策 2026-10-12 记录。原循环废弃，只复用工程骨架。

## UI 呈现方向（用户拍板 2026-10-30）：水墨影刃（参照《影之刃零》画风）

用户要求「整个 UI 呈现全部重来」（不是改画），历经三版：风象图（被否「过不了，不好看」）、
极简软色（未评）→ 用户指令「影之零刃的画风了解一下」→ 研究《影之刃零》真图（官方主视觉、
水墨地图、实机截图）后落地**水墨影刃**方向。研究记录见 `PBZ-STYLE.md`。

核心：**水墨是容器，可爱是内容**。绢底天空 + 浓淡墨山/树影 + 雾带 + 朱砂落日（月白月亮）；
巨树满屏构图（viewBox 320×700）；小鸡与坐骑保持彩色 = 画卷上的朱砂点；朱砂唯一强调
（航迹进度/主按钮/引导圈/纪念品印章）；骨白文字；墨色卡片（发丝描边）；宋体标题。
教训：装饰不铺满全场——雾只两三条、晕染只给山影、印章只给纪念品。

## 变更记录

| 项 | 决定 |

## 核心循环 v1

```
树屋平台（收三叶草）→ 摇铃召唤坐骑 → 坐骑落地 → 点一下登机 → 起飞
→ 自动飞行（横版卷轴，浮游三叶草可点收）→ 随机进入滑翔段（可操控：上升/俯冲、乘气流、穿光圈、躲乌云）
→ 降落结算（目的地明信片卡：三叶草 + 纪念品）→ 回家
```

- **时间**：旅程用真实时间戳（放置安全）。自动段 ~2 分钟，滑翔段 ~28 秒在起飞后 45 秒处触发。
- **离线追赶**：关掉再开 = 一次 `tick(now)` 快进；中途错过的滑翔段自动跳过（结算只给基础里程），
  交互只在"人在场"时发生——符合放置引擎的第 1、2 条规则。
- **坐骑选择**：按时刻表定（6–18 点飞鼠，其余猫头鹰），可测、零随机；后续加"稀有坐骑"再引入 rng。

## 坐骑策略表（新增坐骑 = 加一行配置 + 一组美术）

| 字段 | 说明 |
|---|---|
| `id / name / art` | 标识、名字、美术函数名 |
| `dayNight` | 白天 / 夜行（决定天空配色 + 结算明信片光线） |
| `speed / glideLift` | 巡航速度、滑翔升力系数（影响操控手感） |
| `wingspan / bobbing` | 翼展、颠簸幅度（美术参数） |

## 技术方案

- **分层不变**：`data.js`（表+配置）→ `engine.js`（状态机+经济，UMD 可测）→ `art.js`（坐骑+天空+明信片）
  → `world.js`（两个场景：出发台 + 天空，热点坐标从绘制模块导出）→ `ui.js`（渲染+交互）→ `main.js`（装配+输入策略）。
- **乘客 = 小鸡**（world.js 的 riderChick，绒球身+豆眼，形状少画不崩）；scene.js 保留为青蛙风格实验室（dev 页专用）。
- **滑翔输入策略表**：指针/触摸拖动、方向键、戒指倾斜（体感，未真机验证前标注 unverified）。
- **新手引导**：复用引导机制，新步骤从状态推导（无行程→点铃铛；坐骑落地→点登机；滑翔开始→拖动上下）。

## 风险与测试点

1. 飞行物理（速度/俯仰/气流/碰撞）纯函数化，Node 可测；
2. 状态机迁移：旧存档（旅行青蛙档）不 brick——`migrate` 把不认识的字段丢弃并重置为 v2 新档；
3. 夜行天空配色：**月蓝色灰，不是纯黑**（远景不能糊成黑块）；
4. 滑翔段与自动段的相位切换由 `tick` 驱动（UI 只读相位），避免 UI 和引擎两套时钟打架；
5. 引导断言要探「动手前」的初始态；
6. 连拍视图里引导纸片自动隐藏（沿用 guideOff）。

## UI 呈现方向（用户再次拍板 2026-10-30）：吉卜力晴空绘本

上一版「水墨影刃」落地后被否，理由：主题装饰铺满全场（网格/印章/罗盘/虚线日志/歪斜卡片）=过满即丑；
墨黑 chrome=太素。本轮改向**吉卜力晴空绘本**（参照《魔女宅急便》《千与千宿》晴空）：
通透饱和蓝天、大朵厚白云（圆滚滚、带淡淡底面影、分层视差）、阳光通透、有机圆润形，
第一眼「好可爱好明亮」。

- **场景（world.js PAL + launchScene）**：白天天空垂直渐变 `#67b9e8 → #8fd0ef → #b6e3f5 → #c8ecf7`；
  2–3 朵厚白云分层视差；太阳 = 暖黄白 halo（柔和不过曝，画在云后保证可见，位置 cy≈106 的雾间天空带）；
  远山 = 浅蓝 `#9fb8d8`；树冠 = 圆润卡通绿（亮 `#79c06a` / 深 `#54994e` + 高光 `#a4d98a`）+ 暖棕树干 `#9c6b44`；
  夜 = 靛蓝星空渐变 + 浅黄圆月 + 深蓝云。
- **UI（style.css / flight.css）**：奶油白卡 `#fffdf6`、深墨绿字 `#2e3a33`、暖黄强调 `#f2a93b` **全 UI ≤3 处**
  （主按钮 / 航迹进度 / 纪念品印章）；圆角统一 ~16px（小胶囊/圆形按钮用 999px）；软阴影；chrome 表面零装饰纹样；
  HUD 白胶囊 + 大圆角；黄油金 `#e8c05a` 只给铃铛/引导圈/待收脉冲等功能信号。
- **铁律**：场景满屏出彩，chrome 安静；玩家内容（坐骑 + 小鸡）保持彩色（art.js 禁改）；花的胆子花在一处。
