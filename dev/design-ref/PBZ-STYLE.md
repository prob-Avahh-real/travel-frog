# 风格研究：《影之刃零》(Phantom Blade Zero) 画风拆解与移植

> 用户指令「影之零刃的画风了解一下」→ 研究记录。参照物：官方主视觉、实机截图、
> 游戏内 8 张手绘水墨地图（PCGamer/评测图）。游戏：灵游坊 S-GAME，UE5，
> 2026-10-29 发售，媒体均分 88。官方美学自称「功夫朋克 Kungfupunk」。

## 一、它的视觉语言（从真实图面拆出，非传闻）

| 维度 | 事实 |
|---|---|
| 底色 | 深：墨绿黑 / 灰黑宣纸底（主视觉=深绿暗部；地图=灰黑纸底） |
| 主体 | 黑甲 / 墨色山峦，低对比、柔光散射，没有艳色打光 |
| 强调色 | **朱砂红**（地图红色标记点、血、落日）+ **金**（武器饰件、铃铛类小件） |
| 材质 | 水墨晕染（山峦浓淡三层）、雾、纸纹；金属冷硬只属于"朋克"部件 |
| 文字 | 印章 + 题字（地图左下角 PANGZHEN 印章式落款）+ 书法感标题 |
| 氛围词 | 幽暗 · 古典 · 冷峻（动作/战斗面）；地图面是 古典 · 宁静 · 神秘 |

**最重要的一个事实**：它的**地图/导航呈现**就是「手绘水墨画」——宣纸灰黑底、
浓淡墨晕染地形、朱砂红标记点、印章落款，不标精确目的地。这正是我们游戏
（以"飞行旅程"为主体的 UI）要借的那张皮。

## 二、移植原则（frontend-design：翻译风格，不复制题材）

《御风启程》是治愈系旅行游戏，不是暗黑动作。**不抄它的暗和杀，抄它的容器**：

1. **水墨是容器，可爱是内容**：场景换水墨山河（绢底天空 + 浓淡墨山 + 雾带 +
   朱砂落日/月白月亮）；小鸡和坐骑**保持彩色**——它们就是画卷上的"朱砂点"，
   在墨色底上自己会跳出来。
2. **朱砂红唯一强调**：航线进度、主按钮、引导、印章。金只给铃铛（呼应场景里
   的铜铃）。骨白 = 文字/线条色。
3. **UI chrome 走"墨件"**：墨黑底、骨白线字、发丝描边的墨色卡片；标题用宋体
   （衬线感），正文保持圆润可读；结算纪念品做成**朱砂印章**样式。
4. **克制**：雾带只有两三条、晕染只给山峦、印章只给纪念品。不再把装饰铺满
   全场（上两版 UI 被否的共同教训）。

## 三、设计令牌（落地值 · 2026-10-30 按用户反馈「配色太素」改为青绿淡彩）

用户反馈「配色太素了，清新明亮一些」→ 结构不变，整体从墨黑/绢灰翻成**青绿淡彩**：
墨只留在轮廓线与文字上，底与面提亮提饱和。

```
春纸绿底 --bg #e2e9d8        绢白卡片 --card #f7f4e8 (发丝边 rgba(47,50,42,.14))
墨  字 --ink #2f322a        次级字 --ink-2 #7c806f
朱  砂 --accent #c6402e (暗 #9d2c20)    金 --gold #d8b25c
宋体标题 "Songti SC","STSong","SimSun",serif
```

场景令牌（world.js PAL 青绿淡彩）：
```
day:   sky 水色 #9fd4da→#eef9f6 · 日=朱砂圆盘 #c6402e（画在云上，红日破云）· 远山青 #7fae9a · 近山绿 #5c8c7a · 云=白
night: sky 靛蓝 #1a2337→#4c6894 · 月=月白 #ece8d8 · 山 #3d5372/#334563 · 云 #5b6d92
树冠春山绿：day #7fb06a/#649a56 · night #35402f/#2a3328
树干暖棕 day #7a5c3c；侧影青绿 day #3d5f4e/#4a6d5c；底部晕染 day rgba(52,84,66,.55) / night rgba(8,12,20,.92)
```

坑（已修）：太阳/云最初画在树冠填充区之上被整体盖住——树冠是从画面顶缘垂下的整块填充；
日/月/云必须放在可见的雾间天空带（y≈86–128），且红日画在云层**之后**（红日破云，永远可见）。

## 四、各屏映射

- 出发台：绢底天空 + 朱砂落日 + 松墨树冠 + 两条雾带；铜铃/三叶草/小鸡原色保留
- 飞行：水墨山峦滚动 + 骨白雾丝；HUD 进度条 = 墨轨 + 朱砂笔触填充
- 结算：墨色纸卡 + 骨白日志行 + **纪念品 = 朱砂印章**（骨白字）
- 菜单：墨色日志本 + 宋体大标题

## 五、验收

24/24 测试 + 手机/手表双视口冒烟 + vision 逐屏自检（暗底可读性、朱砂是否唯一强调、
彩色角色是否在墨底上跳出来）。
