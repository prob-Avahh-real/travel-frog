## 第一阶改版记录（已完成）

对着原作逐项改「界面语言」，不是改美术细节：

| 维度 | 原作 | 改版前（我的） | 改版后（我的） |
|---|---|---|---|
| 导航 | 无标签栏，左下木牌 + 右下 2~3 个插画按钮 | 底部 6 个文字标签栏 | 无标签栏；左下木牌「准备」，右下 商店/行李/相册 |
| 主画面 | 满屏一张插画 | 平铺 CSS 房间盒 + 多块白卡片 | 满屏一张手绘勾线场景（`js/scene.js`） |
| 庭院 | 属于同一张画 | 独立卡片 + 6×2 方格阵 | 同一张画里的土畦，12 株有机散布 |
| 顶部 | 一个三叶草计数片 | 三叶草片 + 四叶草片 + 称号 + 3 个按钮 | 一个三叶草计数片 + 「+」圆扣 + 菜单片 |
| 面板 | 覆盖式，各自带返回片 | 6 个「屏幕」+ 标签栏 | 4 个覆盖面板，各自带返回片 |
| 提示 | 无（不挡画面） | 画面中央的黑胶囊 toast | 左下的纸片，同屏最多 2 条 |
| 出门状态 | 屋里空着 + 门口提示 | 盖住整个房间的遮罩面板 | 顶部行程小纸片 + 门口一封信 |

## 第三阶改版记录（已完成）：密度、质感、角色收敛

第二阶把「点进去以后那几屏」对齐了，第三阶补的是**一张画的重量**：

| 维度 | 原作 | 第二阶后的我 | 第三阶后的我 |
|---|---|---|---|
| 密度与纵深 | 一屏叠着好几层：梯子、架上罐子、吊篮、柴堆、水桶、前后景 | 大片空墙与空树干，像示意图 | 远景树篱+远树 → 中景（书架/吊篮/毛巾/床）→ 近景（木台草垫篮筐、门口木箱柴堆水缸）→ 前景大叶；庭院补晾衣绳、洒水壶、苔石、栅栏上的鸟 |
| 质感 | 手绘勾线 + 水彩 | 平涂 + 均匀描边（塑料感） | 11 处不规则晕染（暖/冷/白，低透明度）+ 8 处物件底部排线 + 纸纹噪点 |
| 青蛙 | 家里与照片里是同一只 | 家里勾线版、照片里旧平涂版（两套渲染器） | **一个渲染器**：`js/scene.js` 的 `frogFigure` 同时供家里和明信片用，夜景自动换深皮肤；新增守卫测试保证「明信片数据里的姿态都有画法」 |

验证：`npm test` **30/30** · `npm run smoke` 真浏览器 28 项断言全绿（含「每张明信片里必须真有青蛙」）。

## 画风专项：手绘，不要水彩

前一版用「平涂 + 半透明水彩晕染」，被判「画风矬、有重量没质感」。整条路线换掉：

| 手段 | 参数 | 作用 |
|---|---|---|
| 笔触抖动滤镜 | `feTurbulence(0.021/0.028)` + `feDisplacementMap` scale **5.4** | 数学直线变成手抖线；青蛙/三叶草/蜗牛另用 scale 2.2 的轻抖动，避免小笔画糊掉 |
| 描边统一加粗 | `W_MUL = 1.5`，墨色 `#3c352d`（原来 1.3 / `#4b433a`） | 「线比色重」是手绘的第一特征 |
| 主轮廓重描 | 12 条主轮廓画两遍：粗 4px / 透明度 .16 + 细 1.5px / .8 | 笔画的粗细变化（墨迹铺开 + 笔尖收尾） |
| 排线阴影 | 22 片排线 + 7 片交叉排线（笔长、位置带确定性抖动） | 取代水彩晕染：阴影靠线条，不靠色块 |
| 色块内铅笔扫笔 | 19 条同色系深调长扫笔（墙 4 / 木台 3 / 树干 3 / 草地 6 / 土畦 3） | 平涂「假」是因为大色块一尘不染 |
| 纸 | 暖色薄罩 7% + 粗纤维絮状斑 + 细噪点 | 颜色像画在纸上，而不是屏幕色块 |
| 删掉的东西 | 11 处水彩晕染全删；饱和的绿压暗（`#93c264` → `#8fb168`） | 用户明确要求「不要水彩」 |

**一处自己造的 bug（已修）**：主轮廓重描把「树干右缘」一路画到画面底部，但庭院段的树干是被草地盖住的 →
草地上凭空多出一条竖直浮线。教训：**重描的是「可见的轮廓」，不是「物体的完整边缘」**。

A/B 两档对比见 `ab-style-A-vs-B.jpg`：左 A（抖动 3.6 / 描边 1.3 倍），右 B（抖动 5.4 / 描边 1.5 倍）。**选 B**。

## 面板也上手绘（UI chrome）

场景是 SVG（见上），面板是 HTML/CSS，做法必须不同——**不能给元素本身挂滤镜，那会连文字一起抖歪**：

| 手段 | 实现 | 覆盖 |
|---|---|---|
| 笔触滤镜抖边框 | `index.html` 的 `#ui-defs` 里 `#sketchUI`（`baseFrequency 0.022/0.027`、`scale 3.2`），描边画在 `::before` 上并过这个滤镜 | 只抖框、不动文字 |
| 不等角圆角 | CSS 变量 `--wonky`（`16px 7px 18px 8px / …`）、`--wonky-s`（`10px 4px 12px 5px / …`） | 全 UI |
| 交错歪斜 | `nth-child` 取模/奇偶 ±0.2~0.9° | 相册卡、列表行、商店货格与价格牌、右下按钮、木牌 |
| 纸 | `#app::after` 一层 data-URI 湍流噪点（`mix-blend-mode: multiply`、45%） | 全 App（`pointer-events:none`） |

**两个自己造的坑（已修）**：

1. `.hand/.handy` 里的 `position:relative` 会把本来就 `position:absolute` 的元素顶掉（出门纸片、木牌、价格牌、关窗按钮）→ 这四个必须显式补回 `position:absolute`。CSS 没有「没定位才加」这种写法。
2. 抖框只能挂在 `::before` 上：挂到元素本身，里面的小字会一起被推歪、糊掉。

## 透视专项：从「正侧视剖面」到「室内一点透视 + 庭院俯视」

原作不是平视剖面，而是「屋里一个盒子 + 地面从上往下看」。三格对比见 `compare-3panel-perspective.jpg`
（左 旧平视 / 中 现在 / 右 原作），并排单看见 `compare-perspective-vs-original.jpg`。

| 手段 | 实现 |
|---|---|
| 一点透视骨架 | `VP=(270,220)`、`KROOM=0.45`：后墙 = 门洞按比例收向消失点，左/右墙、天花板、地板 = 连接两者的四边形。**改这两个数，整幅画的进深就变** |
| 地板缝 | `floorY(i)` 走等比数列 —— 一点透视里等距物体的投影就是等比，越远越密 |
| 地面梯形 | 土畦、石板路都是「前宽后窄」的四边形；三叶草的位置与缩放从同一个梯形算（`bedPoint(i)`），UI 热区也用它 |
| 顶面椭圆 + 侧身 | `cyl()`：树桩桌、圆木凳、邮筒、洒水壶、水缸、木箱、蘑菇、灯座全部露顶面 —— 这就是「俯视 + 侧视混合」 |
| 侧墙上的门 | 竖边仍竖直、横边指向消失点（一点透视里竖直线不变，这条最好用） |
| 深度大小差 | `dscale(y)`：越远越小（远树 0.68 倍、近处草 1.05 倍）；三叶草前排 1.42 / 后排 1.05 |
| 明暗分层 | 远景压灰（淡罩 34%）、侧墙压暗、每个物件脚下有落影（`shadow()`） |
| 近景框 | 前景大叶子 + 栅栏 + 灯柱压在最后 |

**这一轮踩到的两个坑**：

1. **局部变量和模块级常量重名**：家具「床」的四点叫 `BEDQ`，土畦的梯形也叫 `BEDQ`（后者在模块级），
   结果 `quad()` 收到 `undefined`、整幅图渲染直接抛错。这类错误构建期不报，只有真跑一次才炸。
2. **CSSOM 会把 `'48.70%'` 规范化成 `'48.7%'`**：热区坐标的断言必须按数值比，按字符串比就会因为
   「格式」而不是「坐标不一致」变红。

## 青蛙：头大身小 + 真实青蛙四肢

反馈原文：「青蛙太丑了，头大身小才萌，按正常青蛙的四肢画，不要强行拟人」。整个渲染器重画：

| 部位 | 改法 |
|---|---|
| 头/身比 | 头宽 62、身宽 40，头整个压在身体上，肚子露在头下 —— 头大身小才萌 |
| 眼睛 | 两个眼球**鼓在头顶**（青蛙的第一识别特征），不是平脸上的两只眼睛；闭眼只在鼓包上画一道弧 |
| 后腿 | 最大的肢体：粗大腿 + 折起的小腿 + **带蹼的平脚**，脚趾三道短线 |
| 前腿 | 短而细，末端只有 2-3 个小趾 —— **没有手**，也不摆人手的手势 |
| 嘴 | 一条横贯脸的大弧线 + 两个鼻点 + 腮红 |
| 姿态键名 | 不变（仍是 `POSES` 的 eyes/arms/legs/prop 开关）—— 内容侧守卫测试按它断言，重画不能改契约 |

**两个自己造的坑**：

1. **闭眼不要画白色眼球**：白眼球 + 一道弧线会读成「白眼上贴了条线」。只在鼓包上画弧即可（1:1 才看得出来，缩略图看不出来）。
2. **身体别被大头完全压没**：头下缘一开始留到 `+10`，结果成了「一个大头长着腿」。头下缘收到 `+4`、身体下移 3，肚子才露得出来。

证据：`frog-poses.jpg`（15 个姿态）、`frog-in-scene.jpg`（室内 1:1）、`frog-before-after.jpg`（改前 / 改后）。

## 第四轮：侧视青蛙 + 面板边框改真 SVG 路径 + 配色提亮

原话三句：「不要正面要侧面」「面板边框改 SVG 路径」「配色鲜亮但不要艳」。

| 项 | 改法 |
|---|---|
| 青蛙改侧面 | 脸朝左；只露一只鼓在头顶的眼球，嘴沿吻部拉成长弧线，鼻点靠吻尖；**远侧的后腿/前腿先画、更深、略偏移**（否则成「一条腿的剪影」）；前腿从「一根线」改成有粗细的短肢 + 小趾 |
| 面板边框 | 新增 `Art.sketchBox(w,h,seed,opt)`：四条边各一条二次曲线（中点带确定性外凸/内凹）+ 两端**出锋 0-5%**，双描（粗淡 + 细实）；`ui.js` 的 `sketchBorders()` 量出实测尺寸后贴一张覆盖 SVG，面板打开 / 内容重建 / 转屏都会重贴；CSS 侧删掉 `::before` 边框与 `#sketchUI` 滤镜 |
| 配色 | 整体提亮提鲜、饱和压在中档：草 `#93c264→#9ccb6e`、墙 `#e7dcc0→#f3e9cf`、红 `#c0503f→#d05a45`、木 `#d8a86a→#e2b678` 等 52 处；墨线仍旧深色 |

**这一轮的三个坑**：

1. **CSS 边框做不出手绘**：四边一样直、角一样圆。要「每条边各自歪 + 角上出锋」，只能生成真路径。
2. **jsdom 量不出尺寸**（`offsetWidth` 恒为 0）→ 边框逻辑在 jsdom 里必须优雅跳过，靠真浏览器冒烟守
   （断言：`.sk-border` 存在、路径够长、`viewBox` 与元素实测尺寸一致）。
3. **正对面的角色像玩偶**：换侧视后，远侧肢体不画就变「一条腿」；画了不压深、不偏移又会糊成一团。

## 还没对齐的（下一步）

1. **物件密度与生活痕迹**（透补齐后上升为首要差距）：原作的树干、屋里、庭院都塞满东西 —— 梯子、
   挂着的工具与罐子、墙上的便条、盘子、晾着的布、成簇的蘑菇与石头、碎木屑地面。我这版每个面还有较多空处。
   透视本身已经补上（见上一节）。
2. **线条的手绘抖动**：我的描边是均匀贝塞尔，原作是手绘线（粗细与走向有抖动）。
3. **原作的次要入口**：抽签木牌、分享到社交、删除照片。只做真的：现在照片页有「存图」（真导出 PNG）。
4. **庭院更细的生态**：原作有更多花草、石头、倒木等散件（现在有草簇/花/蘑菇/苔石/鸟）。

## 边界（重要）

- **布局与信息架构可以对齐，美术必须自己画。** 原作的插画是 Hit-Point 的版权作品；
  本项目只借鉴「勾线 + 水彩质感 + 苔绿/暖棕配色 + 圆体手写字」这套*风格语言*，所有画面均为程序化 SVG 自绘。
- 「旅行青蛙」是原作的官方中文名，自用无碍，若发布需改名。
